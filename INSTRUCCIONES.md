# Publicación del modo de levantamiento

El archivo `app.py` contiene la app completa con el modo de levantamiento integrado.

## Cómo aplicarlo

1. Descarga `app.py` desde esta carpeta.
2. En la copia local del repositorio, reemplaza el archivo existente `app.py` por este archivo.
3. Sube/commitea el reemplazo en la raíz del repositorio `hechavezn-afk/mapa-punta-arenas-kmz`, en la rama `main`.
4. Streamlit Cloud debería reconstruir la app después del commit.

No subas este archivo como `publicacion_modo_creacion/app.py`: debe reemplazar el `app.py` de la raíz.

Los proyectos del modo de levantamiento se guardan en el almacenamiento local del navegador de cada dispositivo. El respaldo JSON sirve para moverlos entre dispositivos.
